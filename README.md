- **17 Özel Efsanevi Seri Koleksiyonu:**
  - *Super Mario Bros Serisi* (Mario 1, 2, 3, Dr. Mario, Mario Is Missing...)
  - *Adventure Island Serisi* (1, 2, 3)
  - *Contra & Super C Serisi*
  - *Double Dragon Serisi* (1, 2, 3, Battletoads crossover)
  - *Teenage Mutant Ninja Turtles (TMNT)*
  - *Mega Man Serisi* (Mega Man 1 - 6)
  - *Castlevania Serisi* (1, 2 Simon's Quest, 3 Dracula's Curse)
  - *The Legend of Zelda Serisi* (1, 2)
  - *Ninja Gaiden, DuckTales, Chip 'n Dale, Donkey Kong, Batman, Bomberman, Tiny Toon...*

- **24 Özel Efsanevi Seri Koleksiyonu:**

  - *Tomb Raider Serisi* (Lara Croft 3D Mezar Keşifleri)

  - *Silent Hill* (Psikolojik korku başyapıtı)
  - *Gran Turismo Serisi* (1, 2)
  - *Spyro the Dragon Serisi* (1, 2, 3)
  - *Grand Theft Auto (GTA 1, 2, London 1969)*
  - *Tony Hawk's Pro Skater (1, 2, 3, 4)*
